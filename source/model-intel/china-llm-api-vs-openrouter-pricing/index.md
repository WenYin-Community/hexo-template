> 数据抓取日：**2026-11-26**。折算汇率：**1 USD = 6.7096 CNY**（中国外汇交易中心 2026-11-26 09:15 中间价；第三方 6.6757 / 6.6782，偏差 0.47%）。
> 口径：官方价按**厂商官网人民币定价**（每百万 tokens）；OpenRouter 按 **endpoints API 实测美元价 × 折算汇率**。**OpenRouter 的 `pricing` 是每 token 美元价，本文已 ×1e6 换算为每百万 token**；缓存字段为 `input_cache_read`。
> ⚠️ **`pricing.discount` 必读**：`0.895` 表示 **−89.5%，且 `prompt`/`completion`/`input_cache_read` 已是折后实付价**；**原价 = 折后价 ÷ (1 − discount)**；**负值 = 溢价**。
> ⚠️ **渠道价按量化精度分档**（`tag` 含 `fp4` / `fp8` / `int4` / `flex`），**不同精度不可直接当同一商品比价**；官方直供渠道通常为 `fp8` 或原生权重。
> ⚠️ **阿里 / 腾讯 / 美团 / StepFun 的官方人民币定价页本轮为 JS 渲染或需登录，未取得可核表**——文中对这几家只列 OpenRouter / CommandCode 实测价，**不估算官方价**。

## 五、结论

1. **GLM 系渠道价差最大**：GLM-5.3 输入低至官方 6%、输出低至 33%；GLM-5.3-Flash 三项均低 70%–80%。**但最低输入与最低输出常来自不同 provider，实际组合价须逐单核算。**
2. **DeepSeek V4.1 Flash 渠道三项全低**（输入 −66%、输出 −44%、缓存 −33%），**是目前最适合走渠道的旗舰档**；V4 Pro 相反——**输入 +32%、缓存 +235%，只适合官方直连**。
3. **Kimi 输入侧套利、输出侧不套利**：K3/K3.1 Pro 输入仅为官方 5%–12%，输出仍为 60%–61%。**RAG / 长文档输入场景走渠道，长输出/代码生成走官方。**
4. **MiniMax、MiMo 价差小且同比例**：M3.1 约五折、M3 约七折、MiMo 仅低 6%–13%。**这两族没有明显套利动机，优先官方或平台内部价。**
5. **官方直连的核心价值是缓存与稳定性**：V4 Pro 的缓存官方 ¥0.15 vs 渠道 ¥0.502；MiMo Flash 缓存官方 ¥0.02 vs 渠道 ¥0.0188（几乎持平）。**缓存命中率高的 Agent 工作流，官方直连往往更省。**
6. **Kimi K2 系列 12 月底下线**：`kimi-k2.7-code` / `kimi-k2.6` 均属 K2，**长期配置应迁移至 K3 / K3.1 Pro**；K2.7 的渠道价（输入 ¥4.03）届时将失去意义。
7. **智谱 GLM-5.4 只对 Coding Plan 开放**：API 未开放、无价格，**不能纳入比价**；Go / CC 侧仍以 GLM-5.3 为最高档。
8. **阿里 / 腾讯 / 美团 / StepFun 官方价本轮未取得**：只列渠道折算价，**不写"官方价 = X"**。需要官方报价时须重抓各厂商计费页，或直接以平台内部价（Go / CC）为准。
